剧情模式怎么用
1. 在聊天页顶部点「剧情」按钮，或打开上面的开关。
2. 每次回复后，模型会在正文末尾附上 3 个选项，聊天页会把它渲染成按钮。

4. 若模型没有按格式输出，程序会安静降级——只显示正文，不显示按钮。
