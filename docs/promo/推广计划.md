## 2. 三个钩子（反复用）

1. **飞行模式实拍** —— 最强的可信度，一图顶千言。
2. **13.8MB / 不用 Termux / 不用电脑** —— 对比 Termux+SillyTavern 的 5 步，你只要装 APK。
3. **32000 张 CC0 原创卡 + 创作者工具** —— 是内容生态，不是光秃秃的客户端。

## 3. 度量

- GitHub **Insights → Traffic → Referrers**：看哪个渠道真的带量，把资源压到 Top 1–2。
- Gitee 仓库访问统计。
- 每次发帖用带渠道标记的链接（如正文里写「来自酷安」），方便归因。
- 关注：star 增速、release 下载量、issue 数。

## 4. 避坑

- **不买 star、不刷量**：会降权甚至封号。
- 别同一时间在多个群发同一段广告；先在社区里正常回答问题。
- Reddit 自推通常限制在总发帖的 ~10%，先参与再分享。
- 中文 App 优先中文渠道，英文渠道要有英文 README 再上。
- 标题不要承诺做不到的事（例如「秒回」要看机型）。
