# 酷安养号与发布避坑（实测记录）

> 日期：2026-10-15　账号：`赵久荣`（显示名），登录用户名已从系统默认 `酷友45030742` 改掉
> 结论：**Lv.0 新号不要直接发带外链的推广帖。先养号。**

## 一、实测确认的硬限制

这几条都是当天在真机上一条条撞出来的，不是猜的：

| 限制 | 表现 | 处理 |
|---|---|---|
| 未绑手机号 | 「我的」页顶部红条「立即绑定手机号，参与社区讨论」 | 必须绑，需短信验证码 |
| 系统默认用户名未改 | 发动态时被强制跳转到「编辑资料 → 修改用户名」，提示「当前为系统默认用户名，修改用户名后才能发布动态」 | 必须先改用户名 |
| **用户名一年只能改一次** | 页面原文：「用户名一年只可修改一次，请慎重修改」；另有限制：不能数字开头、需大于 5 位小于 15 位、不能重名 | **改之前一定要想好**，改错要顶一年 |
| **等级不够，选不了板块** | Lv.0 尝试发到【话题】AI 被拒 | 先养号升级 |
| 相册权限未授予 | 发动态点图片「+」，选择器一片空白，提示「相册访问权限受限」 | 去系统设置给酷安开相册权限 |
| 板块由系统推荐 | 进入「动态」编辑器时，酷安会自动塞一个推荐板块（实测被塞过「联想 AI 平板拯救者 Y900 11」「AI绘画」，都不对口） | 必须手动改掉，否则发到错误的板块 |

## 二、养号节奏（建议第一周）

**做：**
- 每天发 **1 条不带任何链接**的原创动态
- 每天真实回复 **3～5 条**别人在相关话题下的动态（针对内容回复，别复制粘贴）
- 关注 `#数码日常#`、`#AI#` 这类话题，让账号有正常兴趣图谱
- 用真机真网络发，别用自动化批量操作

**不做：**
- ❌ 发任何外链（GitHub / Gitee / APK 下载）
- ❌ 同一段内容同时发多个板块
- ❌ 短时间连发多条
- ❌ 新号第一帖就发「App 介绍 + 下载地址」——这是风控眼里最标准的广告特征

**升级信号：** 等到 Lv.2 以上、或者关注者 > 20，再考虑发正式推广帖。

## 五、用自动化（adb）操作酷安的坑

当天试过用 adb 驱动酷安 App，记录下来免得再走一遍：

1. **`MultiSubmitActivity`（编辑器）未导出**，`am start` 直接启动会抛
   `SecurityException: not exported`。只能走 `monkey -p com.coolapk.market -c android.intent.category.LAUNCHER 1`
   再点「+」→「动态」。
2. **板块列表会插入分组表头行，导致整列下移约 189px**。用旧坐标点会稳定偏到**上一行**
   （实测想点【话题】AI，实际点中「Keep - AI 运动教练」）。
   → 每次点击前都要重新 `uiautomator dump` 取 `CardView` 的 bounds，不要复用坐标。
3. **编辑器首页是动态信息流，`uiautomator dump` 会报 `could not get idle state`**；
   进到编辑器这种静态表单后就能正常 dump。
4. **`adb shell input text` 只支持 ASCII**，中文输入不了。要全自动注入中文得装 ADBKeyboard 这类输入法。
5. **`adb shell pm grant com.coolapk.market android.permission.READ_MEDIA_IMAGES`**
   可解决选图空白。
6. **屏幕一旦转成横屏，所有坐标作废**。可临时 `settings put system accelerometer_rotation 0`
   锁定竖屏（事后记得还原成 `1`）。
7. **同一台手机上一边用浏览器看指令、一边被 adb 操作，会反复抢前台**。
   自动化期间人不要碰手机，否则点击会落到错误的 App 上。
