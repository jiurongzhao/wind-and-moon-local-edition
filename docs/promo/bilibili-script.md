# B 站演示视频脚本（约 75 秒）

> 形式：手机录屏 + 字幕/旁白。开头 5 秒必须给结论，别做长铺垫。

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0:00–0:05 | **飞行模式开关打开**，状态栏出现飞机图标 | 「这个 AI，飞行模式照样聊。」 |
| 0:05–0:15 | 桌面点开 App → 角色列表 | 「风月·本地版，13.8MB，模型全在手机本地跑，不登录、不联网。」 |
| 0:15–0:35 | 点一个角色 → 打字 → 回复**逐字吐出来** | 「打字机效果和在线服务一样顺，0.5B 实测 40 多字每秒。」 |
| 0:35–0:50 | 设置页 → 模型来源 → 展示本地/局域网/云端三种 | 「想省事就用云端 API，想彻底离线就下个 0.5B；模型来源随便换。」 |
| 0:50–1:05 | 剧情模式点选项 → 创作者工具七维评分面板 | 「还有剧情模式、多角色群聊、长期记忆，以及一套写卡工具。」 |
| 1:05–1:15 | 回到角色页，展示 32000 张卡 / 卡包 | 「内置 16 类 32000 张原创卡，全部 CC0。」 |
| 1:15 | 画面定格 + 仓库链接 | 「GitHub / Gitee 搜『风月 本地版』，开源免费。」 |

**标题参考**：「飞行模式也能聊的 AI 角色扮演，13MB，全离线」「手机本地跑大模型，不用 Termux」

**封面**：飞行模式图标 + App 聊天界面对折，大字「13MB · 全离线」。

**发布后**：置顶评论放两处仓库链接 + 常见问题（怎么下模型、支持哪些机型）。
