# 风月·本地版 —— 使用说明

一个**完全离线**的 AI 角色扮演 App。模型和推理都在手机本地跑，飞行模式下也能聊天，
不登录、不联网、不花钱、不上传任何对话。

---

## 一、装到手机上

### 方式 A：用 adb 装（推荐，顺便能推模型）

```bash
cd ~/2/fy
./deploy.sh install        # 装 APK（需先开手机「无线调试」并 ./deploy.sh 会自动连）
./deploy.sh model-small    # 推 0.5B 小模型（490MB，几秒就能用）
./deploy.sh model          # 推 4B 主模型（2.5GB）
./deploy.sh run            # 启动
./deploy.sh logs           # 看日志
```

### 方式 B：手动装

APK 已经放在 `Download/fy.apk`，在文件管理器里点它安装即可（会提示"未知来源"，允许即可）。
模型则在 App 里下载或导入（见下一节）。

> 这个包用调试证书签名。以后要用**同一个** `~/2/fy/debug.keystore` 重新打包，
> 否则覆盖安装会因签名不符失败（得先卸载，App 数据会清空）。

## 二、第一次使用：准备模型

App 启动后如果没模型，设置页会引导你二选一：

**1）直接下载（推荐）** —— 设置 → 模型 → 内置下载源，点一个：

| 模型 | 体积 | 实测生成速度 | 特点 |
|---|---|---|---|
| **Qwen2.5-3B-Instruct（推荐）** | 2.10 GB | **约 9 字/秒** | 速度与质量的平衡点 |
| Qwen3-4B | 2.50 GB | 约 6 字/秒 | 质量更好，需要 4GB 以上空闲内存 |
| Qwen2.5-0.5B-Instruct | 0.49 GB | 约 48 字/秒 | **推荐先用这个**：秒回，智力一般但完全够玩 |

> 速度是在**开启「把模型锁定在内存」（默认开）**的情况下测的。同一台机器上，
> 3B 不开这个选项只有 3.6~4.7 字/秒 —— 差了接近一倍，所以除非内存特别小，别关它。
> 如果内存不够导致加载失败，App 会自动退回普通方式重试，不会卡死。
>
> ⚠️ **真机实测补充**：3B 在可用内存只剩 3.4 GB 左右时，mlock 能成功、引擎也能显示"就绪"，
> 但生成时会疯狂换页（`VmSwap` 涨到 430 MB、`loadavg` 7 以上），**十分钟吐不出一个字**。
> 所以启动前的「内存提醒」不要忽略 —— 见到"内存不够/内存偏紧"就先清后台，或者直接用 0.5B。

走 ModelScope 直链，实测 4 MB/s 左右，**支持断点续传**（断了再点一次接着下）。

**2）从本地文件导入** —— 设置 → 模型 → 导入模型，选一个 `.gguf` 文件
（用系统文件选择器，任何目录都行）。支持 `Qwen3` / `Qwen2.5` 系列等主流 GGUF。

## 三、开始聊天

1. **设置 → 引擎 → 启动引擎**。状态点会依次走 `未启动 → 启动中 → 模型加载中 → 就绪`。
   - 4B 模型加载实测 **19～60 秒**（页缓存热时 19s；内存紧张/存储繁忙时见过 140s）。
     加载期间界面会一直显示"模型加载中"，不是卡死，**等它就对了**（引擎看门狗上限 10 分钟）。
   - 加载完成后引擎常驻，后续对话不再等。
2. 回到**角色**页，点任意角色卡 → 自动插入开场白 → 直接说话。
3. 顶部提示条消失就说明能聊了；没启动引擎时发送会被拦下并提示去设置。

### 角色卡导入 / 导出（SillyTavern chara_card_v2）

社区通用格式，能和 SillyTavern 之类的工具互通。

| 操作 | 怎么用 |
|---|---|
| **导入** | 角色页 →「导入卡」→ 选一个 `.json` 卡，或带 `chara` 块的 `.png` 卡。支持一次导入多张（JSON 数组打包） |
| **导出** | 点角色卡上的 ✏️ 进编辑面板 →「导出」→ 卡片写到 `Download/<角色名>.json` |

- 兼容 v2（`{spec,data}`）、v3、v1（平铺字段）；字段对应：人设→`description`、一句话简介→`personality`、开场白→`first_mes`、示例对话→`mes_example`、系统提示→`system_prompt`，emoji 头像与温度放在 `extensions.fy` 里。
- ⚠️ **点「导入卡」时 App 要在前台**（系统不允许后台 App 拉起文件选择器）。如果只看到"没有选择文件"，把 App 切回前台再点一次。

### 屏幕常亮（别让生成中途熄屏）

生成一轮要十几秒到几十秒，屏幕一黑很烦。设置 → **屏幕常亮** 三个档：

| 档位 | 行为 |
|---|---|
| **生成时**（默认） | 只在生成期间不熄屏；顺手握一把 CPU 唤醒锁，所以**切到后台/息屏也能把这一轮跑完**（否则 Doze 会把推理压停） |
| **一直** | 只要停在 App 里就一直不熄屏，适合慢慢看长回复、慢慢打字 |
| **不保持** | 什么都不握，最省电（代价：息屏后这一轮可能被系统拖慢） |

> 实现上：前台靠 `FLAG_KEEP_SCREEN_ON`，后台/息屏靠 `PARTIAL_WAKE_LOCK`（只在生成期间持有，
> 15 分钟兜底释放）。所以「设置里显示常亮」不等于后台一直耗电。

### 备份 / 恢复（换手机、重装都不怕）

设置页底部两个按钮：

| 按钮 | 作用 |
|---|---|
| **导出全部数据** | 把角色、会话、全部聊天记录、长期记忆、设置打成一个 `fengyue-backup-日期.json` 写到 `Download/` |
| **从备份恢复** | 选一个备份文件，二次确认后**覆盖**当前数据（会提示将覆盖多少角色/会话/消息） |

- 换签名重装、换手机、刷机前先导出一份，出问题随时能回来；
- 备份是纯文本 JSON，不含模型文件（模型几百 MB，另外下就行）；
- 恢复是"覆盖式"，不是合并 —— 所以恢复前的那份数据最好也先导出一份。

### 外观：深色 / 浅色 / 跟随系统

设置页 →「偏好」→「外观」：

- **深色**（默认）：夜色紫调，晚上看不刺眼；
- **浅色**：白天/户外更清楚；
- **跟随系统**：跟着手机的深色模式自动切（系统切换时 App 会立刻响应）。

下面还有**主题色**可选（紫/蓝/青/粉等）：选了之后深色下会自动把强调色提亮、浅色下压深，
保证按钮和标签上的字始终看得清。

### 模型来源：三种用法

**① 手机本地跑（默认，完全离线）**
设置 → 模型管理 → 从内置源下载，或「自定义下载源」粘一个 GGUF 直链 → 回来点「使用」。

**② 连电脑上自建的服务（推荐给内存小的手机）**
电脑上跑 Ollama（`OLLAMA_HOST=0.0.0.0 ollama serve`）、LM Studio 或 llama.cpp server，
然后手机：设置 → **模型来源** → 选「外部服务」→ 填地址（如 `http://192.168.1.5:11434/v1`）→
点「测试连接并列出模型」→ 选一个模型 → 「保存并启用」。

- 手机和电脑要在同一局域网；
- Ollama 默认只监听本机，必须设 `OLLAMA_HOST=0.0.0.0` 才能被手机访问；
- 自建服务一般**不需要**填 API Key。

**③ 用云端 OpenAI 兼容 API（含豆包）**
设置 → 模型来源 → 外部服务 → **服务商预设**里直接选：

| 预设 | 地址 | 模型名怎么填 |
|---|---|---|
| 火山方舟 · **豆包** | `https://ark.cn-beijing.volces.com/api/v3` | 在方舟控制台创建"推理接入点"，填 `ep-…`；也可填 `doubao-…` 模型名 |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` / `deepseek-reasoner` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` / `qwen-max` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` / `glm-4-plus` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `kimi-k2-0905-preview` 等 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` 等 |

选好预设 → 填 API Key → **模型名可以直接手填**（有些服务如火山方舟不提供 `/models` 列表，
这种情况「测试连接」会提示拉不到，手填后保存即可）→ 点「保存并启用」。

> 这种模式下对话内容会离开手机，不再是"完全离线"；Key 只存在本机原生侧（网页层拿不到）。

> 小提示：外部服务模式下，模型跑在电脑/云端，手机只负责显示，所以**生成期间可以随便切后台**，
> 也不会被系统限核（内置引擎在后台会掉到 1/10 速度）。

### 找角色：分类 / 搜索 / 推荐

- **分类**：角色页顶部一排分类（日常治愈、恋爱、悬疑推理、古风仙侠、科幻未来……），点一下只看该类；括号里的数字是每类的张数，「未分类」是没打标签的卡。
- **搜索**：搜索框里输入任意词，会同时匹配**名字、一句话简介、人设正文和标签**；没匹配到会提示你换个词。
- **推荐**：点「🎲 推荐」，按「**还没聊过 → 最久没聊**」的优先级随机给你 3 个，并写明推荐理由；点一条直接开聊，「换一批」再来一组。
- **剧情卡**：卡片名后带「剧情」标记的是剧情卡（自带世界观和群像配角），打开会自动开启剧情模式。

### 内置卡包（160 张原创卡）

角色页「📦 卡包」→ 列出 16 个分类包（每包 10 张，含角色卡与剧情卡）：

- **导入**：单个包点「导入」，或点「全部导入」一次装完 160 张；
- **重复安全**：重复导入只会补齐缺的，不会建重复角色；
- **许可**：全部为本项目原创（CC0-1.0），可自由使用、修改、分发；
- **导出**：任意角色在角色详情里「导出」成标准 `chara_card_v2`，可给别的工具用。

### 搜索聊天记录

顶部「⋯」→ **搜索聊天记录**：输入关键词即搜（搜的是**全部会话**的聊天记录），
点任意一条结果直接跳到那个会话。数据少时走内存索引，切到 SQLite 后端后由数据库做模糊匹配。

### 存储后端（一般不用动）

设置页底部能看到当前后端（默认 **IndexedDB**），也可以切到 **SQLite（实验）**：

- 切换时会**自动把全部数据迁移过去**，原后端的数据保留不动；
- 指定后端打不开时会自动回退（SQLite → IndexedDB → localStorage → 内存），不会白屏或丢数据；
- 日常使用不需要换；SQLite 的价值在于事务/耐用性和超大历史，改完记得确认「导出全部数据」能正常工作。

### 玩法开关（聊天页右上角菜单 / 标题栏）

| 功能 | 怎么用 |
|---|---|
| **剧情模式** | 打开后模型会在正文后附 3 个选项，界面渲染成按钮；点一个就按那个方向推进 |
| **群聊** | 在角色菜单里把多个角色加入当前会话；每轮由一个角色发言（可设轮转/随机），消息上会标说话人 |
| **长期记忆** | 对话超过阈值自动把早期内容压成摘要，之后一直带着；也可在记忆面板手动编辑/立即压缩 |
| **朗读** | 每条 AI 消息右下角 🔊；设置里可开"自动朗读" |
| **语音输入** | 输入框旁 🎤（首次会要麦克风权限） |
| 重新生成 / 编辑重发 / 停止 | 长按消息，或用底部的停止按钮 |

## 四、性能与预期（Redmi Turbo 3 / 骁龙 8s Gen 3 实测）

| 模型 | 生成速度 | 加载耗时 |
|---|---|---|
| Qwen2.5-0.5B Q4_K_M | **4.7 字/秒 ~ 48 字/秒**（真机 App 内实测 4.73 tok/s 生成、144 tok/s 预填充） | 约 2 秒 |
| Qwen2.5-3B Q4_K_M | 内存干净时 8~9 字/秒；可用内存 <3.5G 时会换页崩到几乎为 0 | 21~34 秒 |
| Qwen3-4B Q4_K_M | 约 12 字/秒（短上下文理想值） | 约 17 秒 |

- 线程数默认 6（实测 8 线程反而更慢，小核拖后腿）。
- **GPU/NPU 用不了**：Adreno 的 OpenCL 后端一上 GPU 就被系统杀进程；Hexagon NPU 缺 QNN 运行库。
  所以是纯 CPU 推理，这也意味着不挑机型、不用管驱动。
- 内存占用约 3–4 GB（4B 模型 + 4096 上下文），后台被杀后重进需要重新加载模型。

### 后台会被系统冻住（小米/HyperOS 必看）

这个 App 需要**几十秒**来生成一段回复，而 Android 会把退到后台的 App 判成"缓存应用"冻起来，
连内置引擎一起停摆 —— 表现就是**切出去再切回来，界面点不动**。

- **强烈建议**：设置 → 应用管理 → 风月·本地版 → **省电策略 → 无限制**，
  并允许「自启动 / 后台弹出界面」。这是减少后台冻结最有效的一招。
- App 已经挂了前台服务（通知栏"本地引擎运行中"），能明显缓解，但挡不住厂商的冻结策略。
- 生成中尽量别切走；真被冻过之后切回来，看门狗会自动收尾，直接重发即可。
- 麦克风权限请选 **「仅在使用中允许」**。选「仅本次允许」的话，权限会话一过期
  MIUI 会直接 `one-time permission revoked` **杀掉整个 App**（引擎跟着一起死）。

## 五、出问题怎么办

| 现象 | 原因 / 处理 |
|---|---|
| 引擎状态一直"出错"，日志里有 `Permission denied` | 极少数 ROM 不允许直接执行 APK 自带二进制。App 会自动改用 `/system/bin/linker64` 加载；调试页能看到 `launchStrategy` 走的哪条。若两条都失败，把调试页日志发我 |
| 日志里 `no backends are loaded` | 引擎文件不全，重新 `./build.sh` 打包（别只拷部分 `.so`） |
| `模型文件不存在` | 模型没下完或下到了别的目录；设置页能看到实际路径 |
| 下载中断 | 直接再点一次，会从断点续传（`.part` 文件保留着） |
| 语音输入没反应 | 设置 → 应用权限里给「麦克风」；部分机型的语音识别服务需要联网，纯离线可能不可用 |
| 聊天越聊越慢 | 正常现象：上下文变长后预填充更贵。可在设置里调小"上下文长度"或"携带历史条数" |
| **切出去再切回来，界面点不动** | 被系统冻结了（小米/HyperOS 高发）。先在系统设置里把本 App 的**省电策略设为「无限制」**；被冻过之后切回来，看门狗会自动收尾，重发即可。生成期间尽量别切走 |
| 回复是空的 / 只有一大段"思考" | 设置里「显示思考过程」被打开了，且模型是 Qwen3：思考段会吃掉 token 预算。关掉它即可（默认就是关的） |
| 发送报 `exceed context` | 已内置两道保险（估算留 1.25 倍余量 + 引擎 `--context-shift`），理论上不会出现；真遇到就把上下文长度调大 |

## 六、出问题了怎么给我反馈（不用 adb）

App **启动 5 秒后会自动**把一份诊断报告写到 `Download/fy-diagnostics.txt`，
引擎每次进入「就绪 / 出错」也会刷新一次；调试页也有「导出诊断」按钮可手动触发。

报告里包含：机型/系统/ABI、`nativeLibraryDir`、可用内存、引擎状态与启动方式、
**启动时自检结果**（会真的跑一次 `llama-server --version`，两种启动方式都试）、
最近 80 行引擎日志、模型文件列表、资源服务器端口。

Termux 里一条命令看结果：

```bash
cd ~/2/fy && ./checkup.sh
```

它会告诉你：App 装没装、诊断报告有没有、引擎自检过没过、模型在不在。

## 七、数据在哪

- 角色卡 / 会话 / 记忆：App 私有目录的 IndexedDB（网页层），路径在 `appInfo().filesDir` 下。
- 模型：`files/models/`（设置页显示完整路径）。
- **卸载 App 会一起删掉**。要留存角色和会话，用设置页的导出功能备份成 JSON。
